### [Mini Judge – Web Classroom + Online Judge](https://github.com/TLN606/Django-Judge)

An online classroom with automatic code grading, built with **Python / Django 5.2**.
Teachers create classes and assignments with test cases; students join with a class code, submit **C++ or Python**, and get instant verdicts (Accepted, Wrong Answer, Compile Error, Runtime Error, Time Limit).

- 👥 Role-based access (Teacher / Student), class codes, kick / ban / unban
- 📦 Problem management with test cases and ZIP import / export
- ⚙️ Custom judge core: `compiler → executor → checker → service`
- ✅ **121 tests, 93% coverage**, enforced at ≥ 80% in CI
- 🐳 Docker Compose (Django + PostgreSQL) and a GitHub Actions pipeline: lint → test → build → deploy to Render

`Python` `Django` `PostgreSQL` `GitHub Actions` `Render`

> 👥 Team project for Software Engineering (Group 2 – D23CTC2).
